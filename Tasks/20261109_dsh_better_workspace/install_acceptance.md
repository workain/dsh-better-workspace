# Подключение для проверки владельцем

После отдельного явного подтверждения владельца проверенный Workain tarball `0.41.0-workain.1` подключён штатным `plugin_manager`. PR остаётся открытым, main не сливался; npm release и теги не создавались.

## До изменения

За пределами Git сохранён закрытый snapshot всего web-профиля с symlinks, версиями и hash управляющих файлов. Hash проверен до и после копирования; snapshot сброшен на диск. Точный артефакт размещён по неизменяемому content-addressed пути, SHA-256 `3e2ef52967e278a2eaa5e7b120f562e21a3632dc070e4b7a773534626e0ee89c`.

Первый вызов установщика отказал до записи из-за пустого optional registry; неизменность профиля подтверждена. После явного указания фактически настроенного registry штатная установка завершилась `application=applied`, без разрешения install-скриптов и без version exemption.

## Прочитанный результат

- Добавлена только зависимость проверенного форка, прежние зависимости и pnpm overrides сохранены. Действовавшие Cordis root/patch побайтово не менялись.
- Установленный src побайтово совпадает с reviewed исходниками. Host fiber включён и active.
- Процесс рабочего сервиса не перезапускался.
- Read-only API подтвердил действующие LLM/credentials/OAuth/Board/Telegram/map/schedule/goal возможности, без failed enabled fibers. Искусственных model/Telegram/Tracker действий не выполняли.
- Отдельный Chromium открыл именно существующую GUI: `.bw-root` ровно один, корневого recovery-экрана нет, pageerror 0. Реальные названия, cookies, auth URL и скриншоты не экспортировались. Мутационных кликов в автоматической live-проверке не было.

## Проверка владельцем

1. Обновить страницу Ctrl+F5.
2. Кликнуть имя неназначенного воркспейса: выбрать существующую управляющую сессию в диалоге и подтвердить. Для смены назначения доступен пункт «Управляющая сессия…» / `Managing session…` в меню воркспейса.
3. Последующий клик по имени должен открыть выбранную сессию; отдельная стрелка должна только раскрывать/сворачивать дерево.
4. Проверить, что закрепление осталось независимым. Массовое переименование реальных групп для первого smoke не нужно.

Рабочие назначения автоматом не выбирались; реальным сессиям не меняли имена, pin/archive/group/order. Человеческая визуальная приёмка ожидается, это не заявление о её прохождении.

## Возврат штатного списка

Штатно выключить bundle `dsh-better-workspace` и обновить страницу. Это возвращает исходные slot owners без восстановления старых сообщений, расписаний или Telegram offsets. Защищённый snapshot профиля оставлен для диагностики; при восстановлении файлов сначала проверить актуальные изменения, не затирать параллельные настройки.

Закрытие знаний: это эксплуатационное подключение инструмента, не изменение Guard/B3 сущностей, ролей, статусов, форм или доменных решений. Wiki/ontology — NO; shared RAG не перестраивался. Raw snapshot, operation logs и readback хранятся приватно вне Git. Tracker-комментарий ранее отклонён политикой approval, обхода нет.
