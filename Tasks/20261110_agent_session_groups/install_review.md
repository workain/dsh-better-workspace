# Подключение и откат

Worker не устанавливал пакет и не менял production. Candidate0.41.0-workain.3 включает прежнюю Board menu интеграцию candidate2; сам пакет Board не входит в поставку и не обновляется. При старом Board optional menus отсутствуют, grouping tools независимы от Board. Все новые Host modules перечислены files[], runtime dependencies не добавлены.

Перед разрешённой parent-установкой нужен свежий private snapshot профиля/package/lock/patch и текущий graph/source/version readback. Использовать точный tarballSHA из test_evidence, штатный Plugin Manager, не npm latest и не ручную правку профиля. Approval scripts/version exceptions не разрешены этим документом. Readback сначала при неизвестном install outcome, никаких автоматических повторов. Проверить existing URL после refresh, не обещать HMR или заменяющий сервер.

Фактические инструменты появятся только после подключения новой Host версии. Для разрешённой владельцем live демонстрации parent должен выбрать одну idle-сессию, сохранить её exact before title/provenance/archive/pin/member и поместить в временную группу, затем дождаться визуальной проверки владельца перед извлечением обратно. Никаких массовых production опытов worker.

UI/Host rollback — штатное отключение новой bundle и восстановление прежнего exact reviewed package/profile после проверки конкурентных изменений. Это не откатывает пользовательские title writes. Для восстановления заголовка нужен отдельный явный target-only rename/readback; не слепая обратная групповая операция. Нельзя восстанавливать прошлые session history, board DB, schedule или Telegram offsets. Unknown writes не повторять; сервисная fence и replay ledger не durable после restart.
