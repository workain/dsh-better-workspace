# GUARD-508 — компактный выбор группы

Задача: https://tracker.yandex.ru/GUARD-508
Ветка: `task/guard-508-group-picker-style`, от слитой `origin/main`.

## Требование и решение

Возврат владельца после GUARD-507: убрать нижнюю подпись, оставить только выпадашку в стиле выбора workspace; не показывать её, если в выбранном workspace нет групп.

Стиль сверен с установленным WorkspaceChip и HeroShell.module.css: прозрачный фон в покое, штатный фон при hover/open, высота 28 px, отступы 0/8 px, зазор 4 px, шрифт 13/20 px вес 500, штатные иконки папки 16 px и стрелки 12 px. Внутри только выбранная группа или «Без группы», без префикса поля. Accessible label и всплывающая подсказка сохранены; нижняя подпись удалена.

Dropdown и его layout-wrapper не рендерятся, когда список групп выбранного workspace пуст. Вложенные и явно объявленные пустые группы считаются группами. Семантика назначения, проверки доступа, создание сессий и автоматическое имя не меняются.

## Критика и проверка

Причина возврата — прежний компонент применял стиль настроечного select и вертикальную подпись, хотя находился в компактной строке workspace. Исправлен сам компонент, без обращения к DOM другого плагина и без изменения shell.

Независимое code/UX-ревью: принято, блокирующих замечаний нет. Визуальная браузерная проверка агентом недоступна; соответствие стилю проверено по установленному исходнику, DOM-проверки не выдаются за визуальную приёмку.

Добавлены DOM-проверки отсутствия подписи/префикса, нового класса trigger, скрытия в workspace без групп и возврата при выборе workspace с группами.

`npm test`: 150/150 PASS. JS syntax-check и `git diff --check`: PASS. Собрано штатным npm pack, оба изменённых клиентских файла присутствуют в архиве. Версия `0.41.0-workain.14-guard508.1` установлена штатным Plugin Manager: `application=applied`, `warnings=[]`. Код и манифест установленного пакета побайтно совпали с проверенной рабочей копией. Информационное предупреждение pnpm о peer dependencies не препятствовало установке. Для просмотра нужно обновить существующую страницу DSH; визуальная приёмка пользователем ещё не получена.

## Откат и рефлексия

Предыдущая сборка `0.41.0-workain.13-guard507.1` сохранена в task-папке GUARD-507 и может быть установлена штатным Plugin Manager. Настройки и пользовательские сессии не мигрируются.

Урок: компактные элементы в hero должны повторять соседние штатные контролы, а не настройки плагина; пояснение по умолчанию не должно менять высоту строки.

RAG update: deferred to merge/main. Знания о продукте Guard не меняются.
